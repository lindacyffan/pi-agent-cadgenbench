## Step-by-step workflow

Follow this high-level workflow for the CAD generation task.

1. Read `input.png` and organize the printed dimensions, visible views, and
   important features. Use printed dimensions rather than pixel measurements.

2. Establish the main section, base, or primary structure of the part.

3. Add holes, slots, pockets, bosses, walls, repeated features, and other
   explicitly dimensioned details.

4. Call `validate()` and repair the geometry if validation fails.

5. When the model is valid, save the first valid checkpoint by calling
   `export("{OUTPUT}", format="step")` and `save_snapshot()`.

6. Inspect the model using `render_view()`, `measure()`, and cross-section
   inspection where useful.

7. Identify the largest remaining discrepancy between the model and the
   drawing, then make a local correction to the geometry.

8. Validate the corrected model again. If it remains valid, update the exported
   checkpoint and snapshot.

9. Export the final valid model to exactly:

```text
export("{OUTPUT}", format="step")
```

The persistent build123d execution environment carries geometry forward between
steps. Do not discard valid progress unless a repair requires rolling back to
the last valid checkpoint.
