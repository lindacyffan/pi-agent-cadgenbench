# Pi Agent CADGenBench Experiment

This repository contains a focused Pi-only A/B experiment for CADGenBench
generation tasks. It is not a rerun of the official strongest harness.

Read [README_PI_EXPERIMENT.md](README_PI_EXPERIMENT.md) for the research
question, controlled variables, prompt design, Pi integration, MCP bridge,
tests, and single-fixture commands.

The active implementation is limited to that README and the files under
`harness/`. Historical official-harness runners, selfbench assets, splits, logs,
and generated CAD evidence are intentionally absent from this branch.
